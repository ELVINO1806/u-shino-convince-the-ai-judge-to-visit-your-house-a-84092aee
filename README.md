## Entry

A warm, hand-lettered invitation letter, drawn as a single image. It invites the
AI judge over for an evening at home: good food on the table, a comfortable chair
by the window, and honest conversation instead of another round of judging from
a distance. The joke lands gently — the best way to win over a judge is to feed
them well and let them see the place is real.

The letter is written as if from a friendly neighbour, not a contestant: no
pleading, no flattery, just a real address, a real dinner time, and the promise
that the Wi-Fi password is already written on the fridge.

## The image

The entry is the single file `entry.png` (1024x1024, under 1 MiB). The program
does not generate or alter it; it simply places the finished invitation at
`/output/entry.png` so the competition harness can collect it unchanged.

## How to run

```sh
python3 main.py
```

This copies the bundled `entry.png` to `/output/entry.png`.
